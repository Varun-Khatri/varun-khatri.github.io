The fold mechanic

The player exists in one of two world states at a time — Overgrown (lush ruin, warm amber light, vines, cracked concrete) or Sterile (clean lab, cold blue light, humming machines). Using hand gestures, they pull elements across the boundary: a vine from Overgrown anchors a platform in Sterile; a powered console from Sterile activates a door in Overgrown. Puzzles require reasoning about both states simultaneously.

🌿 Overgrown world

Warm, amber-lit ruin. Vines, broken floors, flooded corridors. Objects are organic, heavy, unpowered. Physics-driven. Time feels slow.

Anchor points Weight puzzles Growth triggers

🔬 Sterile world

Cold, blue-lit operating lab. Powered consoles, laser grids, magnetic rails. Objects are electric, lightweight, precise. Logic-driven.

Power circuits Laser paths Magnetic rails
Design pillars

Never frustrating

Inspired by It Takes Two — the world should delight, not punish. Generous checkpoints, forgiving hitboxes.

Aha moments

Inspired by The Witness — each puzzle teaches a rule, then subverts it once the player feels confident.

Mirror dimension feel

Gestures reshape space visually — inspired by Dr Strange. The fold should feel tactile and magical.

Core gestures — world interaction
✊→✋
Pull (Grab + release)
VR: grip button + pull motion
Reach into a portal window and drag an object from the other world into yours. The object retains its world's physics for 3 s then assimilates. Core traversal + puzzle verb.

Rotate (Two-hand twist)
VR: both grips + twist wrists
Rotates a portal frame or a scripted object/group. Aligns geometric keys, redirects laser beams, opens new sight-lines between worlds. Also rotates platforms for angle-based jumps.

Scale (Two-hand spread/pinch)
VR: both grips + spread or pinch
Expand a window into a full walkable portal, or collapse it to a magnifying lens (view-only). Also scales object groups — stretch a platform section to bridge a wider gap.
PortalsPlatform groupsLens mode

Fold (Two-finger pinch toward each other)
VR: both index fingers pinch inward
Folds a section of the current world, bringing an identical spatial region from the other world forward. Reveals hidden geometry, bridges destroyed sections, exposes alternate paths. The signature Dr Strange moment.

🤚
Anchor (Open palm hold)
VR: open palm facing object, hold 0.5 s
Pins a pulled object in mid-air, freezing its physics. Used to create temporary platforms, prop open doors, or hold beams steady while solving timed puzzles. Anchored objects glow with world-color aura.

Script-trigger (Point + flick)
VR: point at object, wrist flick
Triggers a scripted move/rotate/scale animation on tagged objects. Think: pressing a button with style. Used to start conveyor belts, rotate world sections, extend bridges on rails. Replaces generic "interact" button.

Gesture combinations

Pull + Anchor → floating object bridge  |  Fold + Rotate → re-orient the folded slice  |  Scale (expand) + Pull → walk through and grab simultaneously  |  Script-trigger on a folded object → animated sequence in the merged state

Each level is assembled from reusable modules. Build a module once; reuse with world-state swap (same geometry, different dressing). Overgrown variants use letter suffix O, Sterile uses S.

Base modules
A
Straight path navigation
Linear corridor/platform run. No gaps. Safe practice space. Variations: A1 narrow ledge, A2 wide with debris, A3 sloped ramp, A4 moving floor (slow belt). Teaches basic locomotion + world switch.
B
Gap platforms traversal
Platforms with gaps requiring jumps or Pull to bridge. B1 small gaps, B2 timed gaps (platforms move), B3 asymmetric (gap only visible/crossable from one world), B4 chain of 3-4 gaps.
C
Obstacle course avoidance
Moving hazards, laser grids, swinging arms. C1 single hazard lane, C2 staggered hazards, C3 hazard exists only in one world (fold to avoid), C4 hazard must be redirected using Rotate.
D
Mechanic sandbox tutorial
Isolated space teaching one mechanic. D1 Pull intro, D2 Rotate intro, D3 Scale intro, D4 Fold intro, D5 Anchor intro, D6 Script-trigger intro. Each D module = 60-90 s teach + practice loop.
Compound modules (reuse base geometry)
E
Gap + Navigation A+B remix
Straight path interrupted by gaps. Pull or Fold to bridge. E1 one gap mid-path, E2 alternating floors (each world has different gap positions), E3 moving path with one gap.
F
Obstacle + Mechanic C+D remix
Hazard course that requires an active gesture to pass. F1 Rotate a mirror to redirect a laser away, F2 Fold to bypass a section entirely, F3 Anchor a swinging beam to create a safe window.
G
Cross-world puzzle room signature
Enclosed room where both worlds are visible through portals. G1 single Pull+Anchor solution, G2 multi-step chain (3 objects), G3 timed sequence, G4 with scripted animation trigger.
H
Vertical climb height + drama
Vertical shaft. H1 static ledges, H2 world-alternating ledges (some only in Overgrown), H3 with falling hazards, H4 scripted elevator triggered by gestures.
X
Boss / set-piece climax
Large unique module per chapter. Uses all mechanics introduced so far in one dramatic sequence. X1–X5 = one per chapter. Non-reusable by design.

5 chapters × ~3 levels each. Each level = 2–5 modules chained. Target 8–15 min per level.

Puzzle archetypes

Cross-world bridge

A gap exists in one world but not the other. Pull + Anchor a platform from the intact world to bridge the gap in the broken one. Simplest puzzle type — ideal for Module B variants.

PullAnchor

Power transfer

A powered console in Sterile needs to reach a door in Overgrown. Pull the console partway through a portal, scale the window so the power beam reaches the receiver. Multi-step with visual cause-effect feedback.

PullScale

Geometric key

A portal frame has a shaped aperture. Rotate an object pulled from the other world until its silhouette matches. Shadow-puzzle feel (The Witness DNA). Frame + object must share one world to lock.

RotatePull

Terrain fold

A destroyed walkway in one world is intact in the other. Fold that section — peel the intact floor over the broken one. Hold the fold while walking across. Let go when on the other side.

Fold

Scripted sequence

An object has a scripted animation path (rotate, translate, scale). Script-trigger starts it. Puzzle = time your movement with the animation, or use another gesture to modify the path mid-sequence.

Script-triggerRotate mid-anim

Hazard mirror

A laser or hazard in Sterile blocks progress. Pull a reflective surface from Overgrown (old mirror, water surface) and Rotate it to redirect the beam into a receiver elsewhere. Beam path visualized as a line in both worlds.

PullRotateAnchor
Escalation pattern per chapter

Ch1: one gesture → Ch2: two gestures chained → Ch3: three gestures, timed → Ch4: three gestures + scripted objects → Ch5: all gestures, player-authored solution (multiple valid paths). Never add a new mechanic to a combat-pressure situation — always teach in a safe sandbox (D-type module) first.

Setup
Dr. Asha Voss wakes on a cold lab floor. The station is quiet. The lights flicker between two frequencies — one warm, one cold. She doesn't know how long she's been here. She doesn't know which version of the lab is real.

Act 1 — The Signal

Asha discovers the Fold Gloves — experimental haptic interfaces. The station exists in two states simultaneously. Logs reveal a quantum resonance experiment went wrong 3 years ago. The station split — but kept running.

Act 2 — The Fracture

The two worlds are destabilising — objects from one bleed into the other. Asha finds evidence she caused the split. A second signal — someone else is in the station, in the other world.

Act 3 — Resolution

The other person is Asha — her counterpart who stayed behind when the split happened. Together (in a single-player co-op framing — the player controls both), they fold the two worlds back into one. One Asha ceases to exist. The player chooses which.

Environmental storytelling

No cutscenes. All story in: audio logs (Sterile world), journals/drawings (Overgrown), and environmental contrasts — same room in both states tells a chapter of the story just by what changed.

World state meanings

Overgrown = memory, the past, organic truth, what was left behind. Objects are personal — family photos, hand-written notes, plants Asha grew.

Sterile = logic, the present, institutional cover-up, what was preserved. Objects are impersonal — printed reports, sanitised equipment, backup drives.

Meta Quest 3 (standalone) + PC VR via SteamVR

Vibe-coding strategy (minimum time)
Phase 1
Grey-box prototype — Godot scene with XR rig + 1 gesture (Pull) + 2 cube worlds (colored differently). No art. Prove the world-swap mechanic works. Target: 1 weekend.
Phase 2
Module builder — build D1-D4 modules (gesture sandboxes) with free assets. Lock down gesture feel. Target: 2 weeks.
Phase 3
Level 1-1 + 1-2 — assemble from modules. Add narrative audio logs. Prove the module system works. Target: 1 month.
Phase 4
Chapter 1 complete — all 3 levels, art pass, SFX, first playtest. Target: 2 months total.
Reuse rule
Every module = a Godot scene. World variants = one scene with an exported bool is_overgrown that swaps material sets + object visibility. Zero duplicated geometry.

Key Godot scene structure

├── XROrigin3D (player rig)
